# 《拔草日记》购物推广网站 — 软件测试报告

---

## 一、测试概述

### 1.1 项目背景

《拔草日记》是一款面向18-28岁年轻白领及学生群体的购物推广类网站，旨在帮助用户进行理性消费复盘与社区评价分享。项目采用新粗野主义（Neo-Brutalism）设计风格，以绿黑撞色、粗犷边框、高对比度为视觉特征，共包含15个全响应式页面。

本项目为浙江水利水电学院数字媒体技术专业2022级学生路冰月的毕业设计作品，指导教师为秦胜伟讲师。

### 1.2 测试目的

- 验证15个页面的功能正确性，确保各项交互符合设计预期
- 检验网站在不同浏览器和设备尺寸下的兼容性表现
- 评估网站的性能指标，包括加载速度和资源大小
- 记录开发过程中发现和修复的缺陷，体现迭代优化过程
- 为毕业设计答辩提供完整的质量保证文档

### 1.3 测试范围

本次测试覆盖网站全部15个页面：

| 项目 | 配置 |

| 处理器 | Intel Core i5 |

### 1.5 测试方法

本次测试采用以下方法：

- **黑盒测试**：从用户视角验证页面功能和交互行为
- **兼容性测试**：在多种浏览器和设备尺寸下验证页面表现
- **性能测试**：使用 Lighthouse 工具评估性能指标
- **回归测试**：在缺陷修复后验证功能恢复正常
